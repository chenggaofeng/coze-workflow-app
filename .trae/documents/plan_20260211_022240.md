# Coze 工作流平台完整功能开发计划

## 需要实现的功能

### 1. 数据库表结构更新

* 在 `users` 表添加 `role` 字段（user/admin）

* 创建 `invite_codes` 表（code, duration\_hours, is\_used, used\_by, created\_at）

* 创建 `workflows` 表（id, name, description, coze\_workflow\_id, input\_params, created\_at）

### 2. 管理员权限系统

* 修改认证逻辑，添加管理员角色检查

* 创建管理员专用的 API 端点保护中间件

### 3. 邀请码管理功能

* 创建 `/api/admin/invite/create` API（生成邀请码）

* 创建 `/api/admin/invite/list` API（查看邀请码列表）

* 创建 `/admin/invite` 页面（邀请码管理界面）

### 4. 工作流管理功能

* 创建 `/api/admin/workflow/create` API（添加工作流）

* 创建 `/api/admin/workflow/update` API（更新工作流）

* 创建 `/api/admin/workflow/delete` API（删除工作流）

* 创建 `/api/admin/workflow/list` API（工作流列表）

* 创建 `/admin/workflow` 页面（工作流管理界面）

### 5. 修改注册流程

* 修改 `/api/auth/register` API，添加邀请码验证

* 修改注册页面，添加邀请码输入框

### 6. 数据库初始化脚本

* 创建 SQL 初始化脚本，设置默认管理员账号

### 7. 部署配置

* 更新 wrangler.toml 配置

* 执行数据库迁移
